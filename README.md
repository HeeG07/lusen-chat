# 루센 채팅

An independent Android chat client for Minecraft: Java Edition,
currently under development.

Features include saved server lists, server status checks,
and authenticated server chat. The target versions are
1.21.11 and 26.1.2.

Authentication uses MSAL and Microsoft's browser-based sign-in.
The application does not collect Microsoft account passwords.

Minecraft Services API approval is currently pending.
End-to-end authentication testing has not yet been completed.
